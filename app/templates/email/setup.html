Not Configured

The email triage module needs Google OAuth2 credentials to access your Gmail account.

Step 1: Set up a Google Cloud OAuth client (one-time)

  1. Go to Google Cloud Console > Credentials
  2. Click Create Credentials > OAuth client ID > Application type: Desktop app
  3. Copy the Client ID and Client Secret into secrets.env
GMAIL_CLIENT_ID=your_client_id.apps.googleusercontent.com
GMAIL_CLIENT_SECRET=your_client_secret

Step 2: Enable the Gmail API

Go to Gmail API in your Cloud Console and click Enable.

Step 3: Get a refresh token

Run this on your local machine (not inside Docker), where you have a browser. The script reads your Client ID/Secret from secrets.env automatically.

One-time setup (if you haven't already): 

pip install google-auth-oauthlib

Then run: 

python scripts/get_oauth_token.py --scope gmail

A browser opens. Log in as stephbairey@gmail.com (the hub account) and click Allow. Copy the printed refresh token into secrets.env: 

GMAIL_REFRESH_TOKEN=1//0abc...

Step 4: Restart the container

From the repo root, run these two commands:

docker-compose -f docker/docker-compose.yaml down
docker-compose -f docker/docker-compose.yaml up -d --build

restart does NOT reload secrets.env. Must do down then up.
