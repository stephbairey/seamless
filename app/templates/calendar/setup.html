The calendar module needs Google OAuth2 refresh tokens for each calendar account.

Setup steps:

  1. Use the same Google Cloud project as Gmail (same Client ID / Secret)
  2. Enable the Google Calendar API in your project
  3. Run the OAuth token script 3 times, once per calendar account, with scope: https://www.googleapis.com/auth/calendar
  4. Add the 3 refresh tokens to secrets.env:
GCAL_LINGUAINKMEDIA_TOKEN=refresh_token_for_linguainkmedia
GCAL_MJBAIREY_TOKEN=refresh_token_for_mjbairey
GCAL_STEPHBAIREY_TOKEN=refresh_token_for_stephbairey

Calendars:

linguainkmedia@gmail.com — Business/operational
mjbairey@gmail.com — Creative/writing
stephbairey@gmail.com — Home/personal

After adding the tokens, run docker-compose down && docker-compose up -d --build to reload.
