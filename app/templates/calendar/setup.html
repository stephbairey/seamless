Google Calendar OAuth Tokens Required

Not Configured

The calendar module needs a refresh token for each of the 3 calendar accounts. It reuses the same Client ID and Secret from your Gmail setup.

Step 1: Enable the Calendar API

Go to Google Calendar API in your Cloud Console and click Enable. Same project as Gmail (office-automation).

Step 2: Run the token script (3 times)

Run this on your local machine (not inside Docker), where you have a browser. The script reads your Client ID/Secret from secrets.env automatically.

One-time setup (if you haven't already): 

pip install google-auth-oauthlib

Then run 3 times, logging in as a different account each time: 

python scripts/get_oauth_token.py --scope calendar

A browser opens each time. Log in as:

linguainkmedia@gmail.com → GCAL_LINGUAINKMEDIA_TOKEN
mjbairey@gmail.com → GCAL_MJBAIREY_TOKEN
stephbairey@gmail.com → GCAL_STEPHBAIREY_TOKEN

Step 3: Paste tokens into secrets.env

GCAL_LINGUAINKMEDIA_TOKEN=1//0abc...
GCAL_MJBAIREY_TOKEN=1//0def...
GCAL_STEPHBAIREY_TOKEN=1//0ghi...

Step 4: Restart the container

From the repo root, run these two commands:

docker-compose -f docker/docker-compose.yaml down
docker-compose -f docker/docker-compose.yaml up -d --build

restart does NOT reload secrets.env. Must do down then up.
