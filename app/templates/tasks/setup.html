The ClickUp integration needs an API token to connect to your workspace.

Setup steps:

  1. Go to ClickUp Settings → Apps → API Token
  2. Generate a personal API token
  3. Add it to secrets.env:
CLICKUP_API_TOKEN=pk_your_token_here

After adding the token, restart the dashboard container.
